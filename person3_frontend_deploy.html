Phase 5 — Streamlit App & Export

Weeks 13–14
01

Build streamlit_app.py: Sidebar with city dropdown, year range slider, "Run analysis ▶" button. Three tabs: Map view, Trend charts, Export. Use @st.cache_resource for model load.

02

Build map_view.py: use folium.raster_layers.ImageOverlay to overlay classified PNG on OpenStreetMap. Add 5-class legend with class colours. Add year slider to swap overlay layers. Render with st_folium.

03

Build charts.py: Stacked area chart (class area in sq km across years). Line chart (urban growth vs vegetation decline, same axis). Use official class colours (#8a7a6e, #2d5a27, #6ea84e, #4a8fa8, #c8a96e). Render with st.plotly_chart(use_container_width=True).

04

Build export.py: Auto-generate 4-page PDF via ReportLab — cover (city, year range, date), classified map image, area stats table, trend chart. Add st.download_button. Include SRM roll number and project title in footer.

05

Deploy: push repo to GitHub → share.streamlit.io → connect repo → main file = app/streamlit_app.py. Add Copernicus API credentials as Streamlit Secrets (never hardcode). Share live URL with guide.

💡 Cache tip: Use @st.cache_data for processed tiles — Sentinel-2 tiles take 30–90 seconds to download. Caching makes re-running same city/year instant.
