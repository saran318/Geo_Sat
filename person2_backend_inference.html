Phase 3 (Shared) — Inference on Real Tile

Weeks 6–9
01

Receive resnet50_eurosat.pt from P1. Build predict.py: load weights with map_location="cpu", set model to eval(), run batch inference on 64×64 patches.

02

Build stitch.py: use stored patch coordinates from P1 to reassemble predictions into full-resolution classified map. Save as GeoTIFF with correct CRS metadata.

03

Apply SCL (Scene Classification Layer) cloud masking before inference — mask cloudy pixels to prevent misclassification as "water" or "barren". This boosts apparent accuracy by 10–15%.

📦 Deliverable: inference/ folder (predict.py, stitch.py) + first city classified map GeoTIFF

Phase 4 — Change Detection

Weeks 10–12
01

Use GEE Python API to pull one cloud-free Sentinel-2 composite per year (2019–2023) for your city. A composite picks least-cloudy pixel across the year. Export each as GeoTIFF to Google Drive → download to data/processed/.

02

Loop over all yearly GeoTIFFs, run model inference on each, produce one classified map per year as numpy array and GeoTIFF. Keep spatially aligned — same CRS, extent, pixel size.

03

Build diff_maps.py: for each consecutive pair (2019→2020, etc.), create diff map highlighting changed pixels. Count direction changes (e.g., vegetation→urban = encroachment). Save as change_YYYY_YYYY.tif.

04

Build stats.py: count pixel area in sq km per class per year using rasterio pixel size metadata. Store as pandas DataFrame. Export as area_stats.csv — send to P3 for charts and PDF.

📦 Deliverable: change_detection.ipynb — multi-year classified maps, area_stats.csv, diff visualisations

Phase 5 (Shared) — Backend Integration with App

Weeks 13–14

Expose classify_tile() function in inference/predict.py for P3's Streamlit app to import. Ensure it accepts a GeoTIFF path + model and returns numpy classified array.

03

Verify all GeoTIFFs have correct CRS so they overlay properly on Folium map in P3's app. Test rasterio pixel size metadata used in stats calculation.

Phase 6 — Error Analysis

Weeks 15–16
01

Find at least 3 misclassification cases. Common failures: urban shadows → water, sparse vegetation → barren. Document these honestly — evaluators value this over inflated accuracy.

02

Prepare viva answers: "What is IoU and why use it?", "How does cloud masking improve results?", "What would you improve with 3 more months?"

📦 Deliverable: Error analysis section in final report + viva Q&A notes
